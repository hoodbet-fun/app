# hoodbet.fun app

HoodPot dApp for [app.hoodbet.fun](https://app.hoodbet.fun) — deposit, withdraw, prizes on Robinhood Chain.

## Dev

```bash
npm install
npm run dev
```

## Deploy

```bash
npm run build
# deploy dist/ to app.hoodbet.fun
```

## Environment

| Variable | Production |
|----------|------------|
| `VITE_GITBOOK_URL` | `https://hoodbet.gitbook.io/hoodbet-docs` |
| `VITE_LANDING_URL` | `https://hoodbet.fun` |
| `VITE_GITHUB_URL` | `https://github.com/hoodbet-fun` |
